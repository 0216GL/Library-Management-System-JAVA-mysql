# 图书管理系统（Java + MySQL）

本项目 Fork 自 [harismuneer/Library-Management-System-JAVA](https://github.com/harismuneer/Library-Management-System-JAVA)，感谢原作者。

## 基于原项目的更改

- 数据库从 Derby 迁移至 MySQL
- 全面汉化（界面 + 注释）
- 优化了部分功能逻辑

## 技术栈

- Java Swing（GUI）
- JDBC
- MySQL

## 如何运行

1. MySQL创建数据库,导入 `Database Schema` 中的 SQL 语句.
2. 修改数据库连接配置（用户名 root，密码 123456）
3. 在 IDEA 中运行 `Main.java`
